# Update a generated project

**Diátaxis category: How-to guide.** Use this to bring template improvements
into an existing project that was originally generated by Copier.

From the generated project's root, first ensure its working tree is clean and
committed. Then run:

```bash
uvx copier update --trust
```

Copier uses the project's `.copier-answers.yml` to identify the template and
reapply its recorded answers. It performs a three-way merge when both the
project and template changed a file.

Resolve any conflicts, then verify the result with the generated project's
normal checks:

```bash
uv run pytest
uv run tox
```

Files listed in the template's `_skip_if_exists` configuration, including
`README.md`, `pyproject.toml`, `.gitlab-ci.yml`, and the package initializer,
are preserved instead of overwritten. Consult the
[template reference](../reference/template-contract.md#update-behavior) when
deciding whether to incorporate a change manually.
